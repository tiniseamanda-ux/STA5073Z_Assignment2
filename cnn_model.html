The dataset was split by recording session rather than by writer. Sessions 1–3 were allocated to training, Session 4 to validation, and Session 5 to testing. This strategy was chosen because the objective is to evaluate whether the CNN can recognise the same 20 writers across different recording sessions. A writer-based split would instead assess generalisation to writers whose handwriting was not represented during training, which is a different research question. The training set is used to learn writer-specific handwriting features from labelled images. The validation set contains images from Session 4 and is used to monitor learning and guide model selection, such as choosing hyperparameters or determining when to stop training. The test set contains images from Session 5 and is reserved for the final evaluation after model development is complete. This strategy evaluates within-writer, across-session generalisation. The writer identities are shared across all three subsets, but the recording sessions are separated. Therefore, the evaluation assesses whether the model can identify known writers from a later session, rather than whether it can identify entirely unseen writers. Potential data leakage could arise if duplicate or highly similar images occur across sessions, or if data-dependent preprocessing uses information from the validation or test sets. Although the session-based split prevents images from the same session being distributed across different subsets, it does not guarantee complete independence between samples. To reduce these risks, image duplication should be checked, learned preprocessing parameters should be estimated from training data only, and Session 5 should not be used for model selection. Using test results repeatedly to modify the model could lead to overly optimistic estimates of generalisation performance.

A random-image split was considered as a baseline, allocating approximately 60% of images to training, 20% to validation, and 20% to testing. This approach allows each subset to potentially contain images from all writers and recording sessions, providing a baseline for comparison with the session-based split. However, because images are assigned independently, samples from the same writer and session may appear across all three subsets. If handwriting characteristics or image-generation patterns are shared across samples, this could produce optimistic performance estimates. Therefore, this strategy evaluates generalization to randomly held-out images rather than specifically to unseen recording sessions or unseen writers.

2.3 3.1 CNN model builder

build_cnn <- function(filters = 32,
                      dense_units = 64,
                      dropout = 0.3,
                      lr = 1e-3) {

  model <- keras_model_sequential(
    input_shape = c(28, 28, 1)
  ) |>
    layer_conv_2d(
      filters,
      kernel_size = 3,
      activation = "relu",
      padding = "same"
    ) |>
    layer_max_pooling_2d(pool_size = 2) |>
    layer_conv_2d(
      filters * 2,
      kernel_size = 3,
      activation = "relu",
      padding = "same"
    ) |>
    layer_max_pooling_2d(pool_size = 2) |>
    layer_flatten() |>
    layer_dropout(dropout) |>
    layer_dense(dense_units, activation = "relu") |>
    layer_dense(20, activation = "softmax")

  model |> compile(
    optimizer = optimizer_adam(learning_rate = lr),
    loss = "sparse_categorical_crossentropy",
    metrics = "accuracy"
  )

  model
}

Hyperparameter tuning was conducted by comparing four CNN configurations as shown in Table 1 above, a baseline model and three alternative models. The number of convolutional filters, dense units, dropout rate, and learning rate were varied to assess their effects on validation performance. Model 2 reduced the dense units from 64 to 32 and increased dropout from 0.3 to 0.5. Model 3 further reduced the learning rate from (10^{-3}) to (10^{-4}), while Model 4 also reduced the number of filters from 32 to 16. The models were evaluated using best validation accuracy and minimum validation loss. Model 3 performed best, achieving the highest validation accuracy of 61.00% and the lowest validation loss of 1.4424 among the four configurations. Its parameters were 32 filters, 32 dense units, a dropout rate of 0.5, and a learning rate of (10^{-4}). These results suggest that the lower learning rate improved performance for this configuration.

The selected CNN model was evaluated on the held-out test set to assess its ability to identify writers from their handwriting. The model achieved an overall classification accuracy of 55.1%, indicating that it correctly identified the writer in approximately half of the test images.

As shown in Table 2 above, classification accuracy varied across the five digits. Digit 1 achieved the highest accuracy at 64.8%, followed by digit 2 at 56.1%, digit 4 at 54.4%, and digit 3 at 53.9%. Digit 0 had the lowest accuracy at 46.3%. These differences suggest that the usefulness of handwriting features for writer identification varied by digit, potentially because some digit shapes provided more distinctive writer-specific characteristics than others.

Performance also varied substantially across individual writers, as shown in Table 3. Writers 10 and 17 achieved 100% accuracy, while Writer 14 achieved 99.6% and Writer 5 achieved 89.6%. In contrast, Writers 4 and 12 had 0% accuracy, while Writers 19 and 9 achieved only 18.8% and 19.6%, respectively. This variation suggests that the model learned distinctive handwriting patterns for some writers more effectively than for others.

The confusion matrix in Table 4 provides further insight into these classification errors. The diagonal entries represent correctly classified images, while off-diagonal entries indicate cases where a writer was predicted as another writer. For example, Writer 11 was correctly classified in all 250 test images, whereas all 250 images belonging to Writer 5 were misclassified. Of these, 154 were predicted as Writer 13. Other notable confusion patterns included Writer 10 being predicted as Writer 2 in 200 cases and Writer 13 being predicted as Writer 8 in 82 cases. These patterns suggest that the model struggled to distinguish certain writers, potentially because their handwriting features were similar.
